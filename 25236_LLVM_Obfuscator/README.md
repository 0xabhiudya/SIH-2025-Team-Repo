# SIH Code Obfuscator

This is a multi-pass code obfuscator for C/C++ based on the LLVM 15 compiler infrastructure.

## Supported Systems
This tool is primarily designed for Debian-based Linux distributions such as:
- Ubuntu
- Debian
- Parrot OS

The installation script will attempt to automatically install all necessary dependencies.

## Installation
From the project's root directory, run the all-in-one installation script with sudo:
```bash
sudo ./install.sh
